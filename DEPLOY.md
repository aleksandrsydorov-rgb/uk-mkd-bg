## Шаг 1. Резервная копия и SQL

1. Снять резервную копию базы.
2. Применить четыре файла по имени, строго после уже стоящей версии, от роли-владельца объектов (`supabase_admin` / суперпользователь установки).
3. Записать версии в `supabase_migrations.schema_migrations` только после успешного применения каждого файла (или одним набором после всех четырёх).
4. Повторить запрос выше. Ожидаемый результат: `219` и `20261130338700`.
5. Перезагрузить схему PostgREST:

```sql
notify pgrst, 'reload schema';
```

Либо перезапустить контейнер PostgREST / API.

После перезагрузки должны быть доступны lookup/resolve по секции подъезда
(`property_book_object_identity_key` / `resolve_property_id_for_opening_import`)
с игнорированием архивных объектов при импорте открытий.

## Шаг 2. Образ приложения

Действующий Compose проекта (VPS): `docker-compose.r1-rc8-vps.yml` или
актуальный файл стенда. Переключить только тег образа `amadeus11-app:<новый-тег>`.
Переменные окружения и секрет таймера таксы (`SUPPORT_FEE_CRON_SECRET` /
`EMAIL_CRON_SECRET`, маршрут `/api/support-fee/late-penalties`, расписание после
полуночи Europe/Sofia) этим пакетом не менять.

```bash
# Пример: проверка архива и загрузка
sha256sum -c SHA256SUMS
docker load -i amadeus11-app-<tag>.tar
docker image inspect amadeus11-app:<tag> --format '{{.Id}}'
# Переключить image в Compose, затем:
docker compose -f docker-compose.r1-rc8-vps.yml --env-file /etc/amadeus11/env up -d
curl -fsS http://127.0.0.1:3080/api/health
```

## Шаг 3. Проверка после обновления

1. Книга собственности: апартаменты с одинаковым номером в разных подъездах
   (например A/1 и B/1) остаются разными объектами; повторный импорт того же
   подъезда обновляет тот же объект, не создаёт дубль.
2. Зависимые открытия (вода, электричество, такса, КР, интернет): строка без
   секции при неоднозначном номере не должна записываться; при указанной секции
   привязка идёт к нужному объекту.
3. Мастер «Бюджет УК»: публикация полностью нулевого плана (все статьи = 0) с
   подтверждением проходит без общего текста «Не удалось выполнить действие»;
   после публикации штатная кнопка ведёт к «Начальным расходам».
4. Таймер таксы поддержки и расписание late-penalties без изменений.
