## Шаг 1. Резервная копия и SQL

1. Снять резервную копию базы.
2. Применить три файла по имени, строго после уже стоящей версии, от роли-владельца объектов (`supabase_admin` / суперпользователь установки).
3. Записать версии в `supabase_migrations.schema_migrations` только после успешного применения каждого файла (или одним набором после всех трёх).
4. Повторить запрос выше. Ожидаемый результат: `215` и `20261130338300`.
5. Перезагрузить схему PostgREST:

```sql
notify pgrst, 'reload schema';
```

Либо перезапустить контейнер PostgREST / API. После перезагрузки должна быть сигнатура:

`admin_upsert_property_book_object(..., p_apartment_number text, ..., p_living_area_sqm numeric, p_touch_living_area boolean)`.

Права импорта без изменений: `execute` на `admin_import_property_book(jsonb, jsonb, boolean, boolean, boolean)` у `authenticated` и `service_role`.

## Шаг 3. Проверка после обновления

1. В мастере первоначальной настройки или в Книге скачать XLSX-шаблон (RU/BG/EN). Сразу после колонки площади апартамента должна быть колонка жилой площади:
   - RU — «Жилая площадь, м²»
   - BG — «Жилищна площ, м²»
   - EN — «Living area, m²»
2. Импортировать или обновить существующий апартамент с общей площадью `85.40` и жилой `62.75` (дробная часть точкой или числом Excel). После перезагрузки карточки на вкладке «Характеристики» видны обе площади.
3. Ручное изменение жилой площади сохраняется. Старый XLSX без новой колонки и файл с пустой ячейкой жилой площади не стирают сохранённое значение.
4. Такса поддержки и капитальный ремонт по-прежнему считают по `properties.area_sqm`, не по жилой площади.
5. Приглашённый собственник без идеальных частей открывает свой апартамент; чужой объект недоступен.

## Номера апартаментов (без расширения правил)

- **XLSX-импорт:** номер должен приводиться к целому (`::bigint`). Буквенные суффиксы и нечисловые значения отклоняются с `apartment_number_invalid`. Ведущие нули в ячейке как текст сохраняются в колонке `text` при записи через импорт (в upsert уходит исходная текстовая строка после успешной числовой проверки).
- **RPC `admin_upsert_property_book_object`:** аргумент `p_apartment_number` — `text`. Пустая строка не затирает сохранённый номер. Карточка передаёт строку как есть (ведущие нули и суффиксы сохраняются при ручном сохранении).
