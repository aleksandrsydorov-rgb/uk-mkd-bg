resolve_support_tariff_for_year(p_billing_year):
- finds support_fee catalog
- latest PUBLISHED version with valid_from <= Jan 1 of year
- ignores cancelled
- requires exactly one base rate > 0
- fail closed (no building_settings / no default 8 / no wall-clock / no future)
