==============================================================================
ARCHITECTURE
==============================================================================

Reusable platform-core adoption module (not Amadeus-hardcoded).

- Module Core key: user_activation (PLATFORM CORE — mandatory)
- implemented=true, default/forced enabled=true
- Not toggleable in Settings; filtered via PLATFORM_CORE_MODULE_KEYS
- Client reject: isPlatformCoreModuleKey in handleSetBuildingModule
- DB: is_platform_core_module_key + set_building_module_enabled guard
- DB trigger: platform_core_prevent_disable_biu
- Access: has_staff_role('администрация') only (role-gated, not toggle-gated)
- Left nav: dedicated standalone group (not under Settings / Personnel / Platform Support)
- Auth.users: only via SECURITY DEFINER admin RPCs (email, created_at,
  email_confirmed_at) — no tokens/secrets

==============================================================================
SOURCE OF TRUTH
==============================================================================

Owners: property_registry_people (active owners) + legacy properties.owner_email
Invites: property_access_invites
Auth: auth.users (safe columns)
Activity: user_activation_profiles (first_login_at, last_login_at,
  last_activity_at, login_count) via throttled user_activation_touch_activity

Identity: unique normalized email; multi-property associations aggregated.

==============================================================================
ACTIVATION STATES (derived)
==============================================================================

NOT_INVITED | INVITED | REGISTERED | FIRST_LOGIN_DONE | ACTIVE | DORMANT

Thresholds (code + SQL constants):
- inactive: 30 days
- online/recent: 5 minutes
- invite stale / needs attention: 3 days
- activity throttle: 5 minutes

==============================================================================
ONLINE DEFINITION
==============================================================================

recently_active := last_activity_at >= now() - 5 minutes
UI explains this is recent activity, not guaranteed open session.
